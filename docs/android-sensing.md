# way-memory Android 采集方案

## 采集分层

### 基础传感器

- 加速度计
- 陀螺仪
- 磁力计
- 重力/线性加速度/旋转向量等系统融合传感器
- 气压计（若设备具备）

### 定位

- Fused Location Provider
- GNSS 原始观测（按设备和权限情况启用）
- 地理围栏不作为高频导航定位方案

### 相机与空间

- CameraX
- ARCore 会话
- Depth API（设备支持时）
- Geospatial/VPS（区域、权限和设备支持时）

## 设备能力清单

App 启动时必须枚举并上报：

- 传感器类型
- 供应商
- 最大范围
- 分辨率
- 最小延迟
- 功耗等级
- 是否可用

不同 Android 手机的传感器集合并不统一，因此所有功能都必须有能力检测和降级路径。

## 后台采集

实时路线学习和导航需要前台服务、持续通知、位置权限和电量策略。后台限制、厂商省电策略和系统终止都必须作为可观察状态显示给用户，而不能假设 App 永远运行。

## 坐标规范

内部统一定义：

- 设备坐标系：Android Sensor Framework 原始轴
- 世界坐标系：ENU（East-North-Up）
- 地理坐标：WGS84 经纬度和椭球高
- 所有转换记录版本和来源
