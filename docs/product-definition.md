# way-memory 产品定义

## 1. 产品愿景

让盲人用户能够记录自己反复走过的路线，并在下一次行走时获得更贴合个人习惯和真实环境的辅助提示。

## 2. 第一阶段目标

选择一条固定路线，连续记录 3～5 次，生成一条可编辑、可回放、带人工标注和置信度的路线图，并在下一次行走时提供基础语音提示。

第一条验证路线建议为：家门口 → 小区出口 → 公共交通入口，长度控制在 500 米至 2 公里。

## 3. 不做的事情

- 不承诺仅依赖手机传感器实现所有环境的厘米级定位。
- 不把一次视觉模型判断直接作为安全指令。
- 不依赖二维码、NFC、Beacon、UWB 或其他外部固定硬件。
- 不在第一阶段同时支持 iOS。
- 不把网页地图当作盲人端的主要交互界面。

## 4. 核心用户流程

### 路线学习

1. 用户启动学习模式。
2. 手机采集可用传感器和定位数据。
3. 用户或陪同人员通过语音/按钮添加标注。
4. 系统记录自然视觉地标候选和环境变化。
5. 网页端检查、修正并发布路线版本。

### 路线导航

1. 用户选择已学习路线。
2. 手机建立当前定位和路线匹配。
3. 到达高置信度节点时播报下一步。
4. 置信度下降时降低指令强度并请求确认。
5. 无法恢复定位时停止复杂导航并提供求助/原路返回选项。

## 5. 成功标准

- 同一路线重复记录后，轨迹能够稳定合并。
- 关键节点可以被人工确认和回放。
- 系统能明确区分高、中、低定位置信度。
- 断网、传感器缺失、视觉失败时有可理解的降级行为。
- 所有轨迹和视觉数据均可导出和删除。
