# way-memory 定位与视觉方案

## 目标

通过 GNSS、IMU、视觉惯性定位、气压和历史路线匹配，估计手机在已学习路线上的位置、方向和置信度。

## 融合顺序

1. 采集并校准时间戳。
2. 用陀螺仪和加速度估计短时姿态/运动。
3. 用 GNSS 提供地理坐标约束。
4. 用 ARCore/视觉特征减少局部漂移。
5. 用气压辅助识别楼层和高度变化。
6. 用历史路线和人工节点进行地图匹配。
7. 输出带来源的融合结果，而不是单个黑盒坐标。

## 自然地标

不部署固定标记，保存环境中的稳定特征候选：建筑轮廓、门、楼梯、电梯、路牌、树木、围墙、路口几何和可见表面特征。

自然地标必须有多次观测和时间衰减，施工、车辆和行人不能被当作永久地标。

## 视觉模型原则

- 模型输出必须带置信度和版本。
- 连续多帧或多次经过确认后，才能升级为路线节点证据。
- 视觉模型不能单独触发高风险转向或道路穿越指令。
- 低光、遮挡、运动模糊时明确降低置信度。
- 优先在手机本地处理高频、低风险信息；上传云端前须获得明确授权。

## 重要限制

纯手机方案可以提升重复路线的个性化定位，但不能保证夜间、雨雾、空白墙面、快速移动、环境大改造和所有室内场景都能稳定视觉定位。
